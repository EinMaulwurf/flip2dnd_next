# Flip2DND Next v1

First signed release of Flip2DND Next, an independently developed evolution of Flip2DND.

## Features

- Flip your phone face down to activate Do Not Disturb, then pick it up to restore sound.
- Adjustable sensitivity and activation delay, optional proximity gating, and schedule windows.
- Filters for media playback, connected audio devices, and the flashlight.
- Custom audio, vibration patterns, and adjustable vibration strength.
- Persistent detection controls, automatic startup, and clear sensor-failure reporting.
- Session restoration that respects manual sound changes and handles Android 15+ DND rules separately from other rules.
- Optional local diagnostic recording and explicit log export for troubleshooting. Recording is off by default; logs are never automatically uploaded.
- Material 3 interface, widget, and Quick Settings tile. No ads or tracking.

## Install

Download **Flip2DND-Next.apk** below. Android 6.0 or newer is required.

The package is `dev.flip2dnd.next`; app version is `1.0.0` (build 1216).
It installs separately from the original Flip2DND and earlier Personal builds.
Disable detection in those apps before using Next.

If you installed a Next debug/test APK, uninstall it before installing this signed
release because the signing keys differ. Uninstalling removes its app data.
Grant the requested permissions after installation. Xiaomi and similar devices
may also require enabling background autostart.

The SHA-256 file lets you check the downloaded APK. Keep this release installed
for future updates signed with the same release key.

## Testing and limitations

Automated unit and Android regression tests cover detection, schedules, feedback,
session ownership, lifecycle control, DND rules, and diagnostic logging.
Device-specific screen-off behavior and overnight battery use still require
physical-device testing. See the repository's reliability and diagnostics documentation.
