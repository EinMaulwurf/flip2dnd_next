# Flip2DND Next v1

First signed release (1.0.0).

- Configurable flip detection, activation delay, proximity gating, and schedule windows.
- Media, audio-device, and flashlight filters; custom sound and vibration feedback.
- Improved background detection, startup, state restoration, and Android 15+ DND handling.
- Material 3 interface, widget, Quick Settings tile, and optional local diagnostics.
- No ads or tracking.

Install **Flip2DND-Next.apk** below (Android 6.0+). If replacing a Next debug/test
build, uninstall it first because the signing keys differ; this removes its data.
