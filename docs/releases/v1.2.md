# Flip2DND Next v1.2

- Activation feedback now finishes before enabling Do Not Disturb or changing the ringer in every mode, so priority and alarms-only policies cannot cut it short during the transition.
- Activation includes a two-second feedback window after your configured delay. Picking up the phone during this window cancels activation.

Install **Flip2DND-Next.apk** below (Android 6.0+). Updates signed Next releases while preserving settings. If replacing a Next debug/test build, uninstall it first because the signing keys differ; this removes its data.
