# Flip2DND Next v1.1

- Set flip tolerance in degrees (5–30°) to choose how flat your phone must be, with existing sensitivity settings migrated automatically.
- Tap the info icons in Flip Behavior to learn the difference between Do Not Disturb and Mobile Ringer, and what each DND and ringer option does.

Install **Flip2DND-Next.apk** below (Android 6.0+). Updates the signed v1 release while preserving settings. If replacing a Next debug/test build, uninstall it first because the signing keys differ; this removes its data.
